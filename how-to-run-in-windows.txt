========================================
دليل تشغيل المشروع على جهازك الشخصي
========================================

مرحباً! هذا دليل بسيط لتشغيل المشروع على جهازك.

--------------------
الخطوة 1: التحضير
--------------------

تأكد من تثبيت Python على جهازك:
- افتح موجه الأوامر (Command Prompt) أو PowerShell
- اكتب: python --version
- إذا ظهر رقم الإصدار (مثل: Python 3.11.0)، فأنت جاهز
- إذا لم يظهر، قم بتحميل Python من: https://www.python.org/downloads/

--------------------------------------
الخطوة 2: إنشاء بيئة العمل الافتراضية
--------------------------------------

1. افتح موجه الأوامر في مجلد المشروع
2. قم بإنشاء بيئة افتراضية:
   python -m venv venv

3. قم بتفعيل البيئة الافتراضية:
   .\venv\Scripts\activate
   
   (ملاحظة: سيظهر (venv) قبل المسار في موجه الأوامر)

--------------------------------------
الخطوة 3: تثبيت المكتبات المطلوبة
--------------------------------------

بعد تفعيل البيئة الافتراضية، قم بتثبيت المكتبات:
pip install -r requirements.txt

انتظر حتى تنتهي عملية التثبيت...

--------------------------------------
الخطوة 4: إعداد قاعدة البيانات
--------------------------------------

أ) الحصول على قاعدة بيانات Neon Postgres:

1. انتقل إلى: https://vercel.com
2. قم بتسجيل الدخول أو إنشاء حساب جديد
3. من لوحة التحكم، اذهب إلى "Storage"
4. اضغط على "Create Database"
5. اختر "Postgres" (ستفتح قاعدة بيانات Neon)
6. اختر اسماً للقاعدة البيانات والمنطقة
7. اضغط "Create"
8. بعد الإنشاء، اذهب إلى تبويب "Settings" أو "Connection String"
9. انسخ رابط الاتصال (DATABASE_URL) - سيكون على الشكل:
   postgresql://user:password@host.neon.tech:5432/database?sslmode=require

--------------------------------------
الخطوة 5: إنشاء ملف .env
--------------------------------------

1. في المجلد الرئيسي للمشروع، أنشئ ملفاً جديداً باسم: .env
   (بدون أي امتداد آخر، فقط .env)

2. افتح الملف بأي محرر نصوص (مثل: Notepad)

3. أضف المعلومات التالية:

# رابط قاعدة البيانات (من Neon/Vercel)
DATABASE_URL=postgresql://user:password@host.neon.tech:5432/database?sslmode=require

# مفتاح الأمان JWT (اصنع نصاً عشوائياً طويلاً)
JWT_SECRET=your-super-secret-jwt-key-make-it-long-and-random-123456789

# كلمة مرور لوحة التحكم (اختر كلمة مرور قوية)
ADMIN_PASSWORD=your-admin-password

--------------------------------------
ملاحظات مهمة لملف .env:
--------------------------------------

- DATABASE_URL: ضع الرابط الذي نسخته من Neon/Vercel (الخطوة 4)

- JWT_SECRET: هذا مفتاح سري لتشفير البيانات
  * يجب أن يكون طويلاً (على الأقل 32 حرفاً)
  * استخدم أحرف وأرقام ورموز عشوائية
  * مثال: "MyS3cr3tK3y!2024@StudentPlatform#Random789"
  * أو قم بتوليد مفتاح عشوائي من: https://randomkeygen.com

- ADMIN_PASSWORD: كلمة المرور التي ستستخدمها للدخول كمعلم
  * اختر كلمة مرور قوية لحماية البيانات

4. احفظ الملف وتأكد من اسمه ".env" بالضبط

--------------------------------------
الخطوة 6: تشغيل المشروع
--------------------------------------

1. تأكد أن البيئة الافتراضية مفعلة (يظهر (venv) في موجه الأوامر)

2. شغّل المشروع:
   python api/app.py

3. إذا نجح التشغيل، ستظهر رسالة مثل:
   * Running on http://127.0.0.1:5000

4. افتح المتصفح واذهب إلى: http://localhost:5000

--------------------------------------
الخطوة 7: إيقاف المشروع
--------------------------------------

عندما تريد إيقاف المشروع:
- اضغط Ctrl + C في موجه الأوامر

لإيقاف البيئة الافتراضية:
deactivate

--------------------------------------
نصائح مفيدة:
--------------------------------------

✓ احتفظ بنسخة احتياطية من ملف .env في مكان آمن
✓ لا تشارك ملف .env مع أحد (يحتوي على معلومات حساسة)
✓ إذا واجهت مشكلة، تأكد من:
  - تفعيل البيئة الافتراضية
  - صحة المعلومات في ملف .env
  - اتصالك بالإنترنت (لأول مرة للاتصال بقاعدة البيانات)

--------------------------------------
في حالة وجود مشاكل:
--------------------------------------

المشكلة: لا يعمل الأمر python
الحل: جرب python3 بدلاً من python

المشكلة: خطأ في الاتصال بقاعدة البيانات
الحل: تأكد من صحة DATABASE_URL في ملف .env

المشكلة: خطأ في تثبيت المكتبات
الحل: تأكد من تفعيل البيئة الافتراضية أولاً
