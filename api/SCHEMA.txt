DATABASE SCHEMA - Student Skills Platform
=============================================

TABLES CREATED:
===============

1. STUDENTS TABLE
   Columns:
   - id (UUID - Primary Key) - Auto-generated unique identifier
   - code (VARCHAR 50 - UNIQUE) - Student code/number
   - name (VARCHAR 255 - NOT NULL) - Student full name
   - email (VARCHAR 255) - Student email address
   - class (VARCHAR 50) - Class/grade level
   - created_at (TIMESTAMP) - Record creation date
   - updated_at (TIMESTAMP) - Last update date
   
   Indexes:
   - idx_students_code (on code column)
   - idx_students_email (on email column)

2. SKILLS TABLE
   Columns:
   - id (UUID - Primary Key) - Auto-generated unique identifier
   - student_id (UUID - Foreign Key) - References students table
   - name (VARCHAR 255 - NOT NULL) - Skill name
   - level (INTEGER, default=1) - Skill level (1-3)
   - description (TEXT) - Skill description
   - category (VARCHAR 100) - Skill category
   - notes (TEXT) - Additional notes
   - created_at (TIMESTAMP) - Record creation date
   - updated_at (TIMESTAMP) - Last update date
   
   Indexes:
   - idx_skills_student_id (on student_id)
   - idx_skills_level (on level)
   - idx_skills_category (on category)

3. STUDENT_EVALUATIONS TABLE
   Columns:
   - id (UUID - Primary Key) - Auto-generated unique identifier
   - student_id (UUID - Foreign Key) - References students table
   - evaluation_date (TIMESTAMP) - Evaluation date
   - overall_score (INTEGER) - Overall evaluation score
   - comments (TEXT) - Evaluation comments
   - created_at (TIMESTAMP) - Record creation date
   - updated_at (TIMESTAMP) - Last update date
   
   Indexes:
   - idx_evaluations_student_id (on student_id)
   - idx_evaluations_date (on evaluation_date)

4. ADMIN_LOGS TABLE
   Columns:
   - id (UUID - Primary Key) - Auto-generated unique identifier
   - admin_id (VARCHAR 255) - Administrator ID
   - action (VARCHAR 100) - Action performed (ADD_STUDENT, DELETE_STUDENT, etc.)
   - table_name (VARCHAR 100) - Target table name
   - record_id (VARCHAR 255) - ID of affected record
   - details (TEXT) - JSON details of the action
   - created_at (TIMESTAMP) - Log creation date
   
   Indexes:
   - idx_admin_logs_admin_id (on admin_id)
   - idx_admin_logs_action (on action)
   - idx_admin_logs_created_at (on created_at)

5. SESSIONS TABLE
   Columns:
   - id (UUID - Primary Key) - Auto-generated unique identifier
   - admin_id (VARCHAR 255 - NOT NULL) - Administrator ID
   - token (VARCHAR 500 - UNIQUE) - JWT token
   - expires_at (TIMESTAMP - NOT NULL) - Token expiration time
   - created_at (TIMESTAMP) - Session creation date
   
   Indexes:
   - idx_sessions_token (on token)
   - idx_sessions_admin_id (on admin_id)
   - idx_sessions_expires_at (on expires_at)

DATA TYPES USED:
================
- UUID: Universally Unique Identifier for primary keys
- VARCHAR(n): Variable-length text up to n characters
- TEXT: Unlimited-length text for descriptions and details
- INTEGER: Whole numbers (skill levels, scores)
- TIMESTAMP: Date and time values
- BOOLEAN: True/False values (not used yet, reserved for future)

RELATIONSHIPS:
==============
- skills.student_id → students.id (Foreign Key, CASCADE DELETE)
- student_evaluations.student_id → students.id (Foreign Key, CASCADE Delete)

This schema is automatically created by running: npm run setup
