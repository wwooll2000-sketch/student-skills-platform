# نظام متابعة مهارات الطلاب - اللغة العربية

منصة ويب شاملة لتتبع ومتابعة مهارات لغة العربية للطلاب مع لوحة تحكم للمعلمين.

## المميزات 🚀

- ✅ واجهة عربية كاملة (RTL)
- ✅ نظام دخول آمن للطلاب والمعلمين
- ✅ لوحة تحكم متقدمة للمعلم
- ✅ إدارة مهارات الطلاب ومتابعتهم
- ✅ نسخ احتياطية وتصدير البيانات
- ✅ دعم الوضع بدون اتصال (PWA)
- ✅ نظام أمان متقدم
- ✅ رؤوس أمان HTTP

## البنية الأساسية 📁

```
project/
├── index.html              # الملف الرئيسي
├── manifest.json           # ملف PWA
├── robots.txt             # توجيهات محركات البحث
├── sitemap.xml            # خريطة الموقع
├── security.txt           # معلومات الأمان
├── config.json            # إعدادات التطبيق
├── .htaccess              # قوانين الخادم
├── service-worker.js      # خدمة الوضع بدون اتصال
├── security.js            # نظام الأمان
├── backup-data.js         # نظام النسخ الاحتياطية
└── README.md              # هذا الملف
```

## الملفات والملفات المدعومة 📄

### `index.html`
الملف الرئيسي الذي يحتوي على:
- واجهة الدخول للطلاب
- لوحة تحكم المعلم
- عرض تفاصيل المهارات
- نموذج إضافة المهارات

### `manifest.json`
يدعم تثبيت التطبيق على الهاتف:
- معلومات التطبيق
- الألوان والمظهر
- الأيقونات

### `robots.txt`
يتحكم في كيفية زيارة محركات البحث:
- السماح بالصفحات العامة
- منع الوصول لصفحات المسؤول
- إشارة خريطة الموقع

### `sitemap.xml`
خريطة الموقع لمحركات البحث

### `.htaccess`
قوانين خادم Apache:
- ضغط الملفات (GZIP)
- تخزين مؤقت ذكي
- رؤوس أمان HTTP
- منع الوصول للملفات الحساسة

### `service-worker.js`
يفعل الوضع بدون اتصال:
- تخزين الملفات محلياً
- تحميل الملفات المخزنة عند انقطاع الاتصال
- تحديث الذاكرة المؤقتة

### `security.js`
نظام الأمان:
- التحقق من محاولات الدخول
- تشفير البيانات الأساسي
- تنظيف المدخلات لمنع XSS
- تسجيل الأنشطة

### `backup-data.js`
إدارة البيانات:
- إنشاء نسخ احتياطية تلقائية
- تصدير البيانات كـ JSON
- استيراد البيانات من ملف
- سجل النسخ الاحتياطية

### `config.json`
إعدادات التطبيق:
- كلمة مرور المعلم
- إعدادات الأمان
- تفعيل المميزات

## كيفية الاستخدام 🎯

### للطالب:
1. أدخل رقم الطالب الخاص بك
2. اعرض مهاراتك المفقودة
3. انقر على الملفات لعرض الشروح

### للمعلم:
1. اضغط على ⚙️ في الزاوية العلوية اليسرى
2. أدخل كلمة المرور: `admin`
3. أضف طلاب جدد وأرقام دخولهم
4. أضف مهارات لكل طالب
5. تابع إنجاز الطلاب

## الأمان 🔐

- حماية من هجمات XSS
- حماية من Clickjacking
- حماية من MIME type sniffing
- رؤوس Content Security Policy
- تسجيل الأنشطة
- تحديد محاولات الدخول

## المتطلبات 📋

- متصفح حديث يدعم HTML5
- اتصال بالإنترنت (اختياري - يعمل بدونه)
- JavaScript مفعل

## الخصوصية والامتثال 📋

- لا يتم جمع بيانات شخصية خارج الموقع
- البيانات تُخزن محلياً في المتصفح
- معايير GDPR الأساسية
- معلومات الاتصال للأمان في `.well-known/security.txt`

## التثبيت على الهاتف 📱

1. افتح الموقع في متصفح Chrome/Firefox
2. اضغط على "إضافة إلى الشاشة الرئيسية"
3. سيعمل كتطبيق عادي

## دعم الوضع بدون اتصال ⚡

- جميع الملفات الأساسية مخزنة محلياً
- يعمل التطبيق حتى بدون إنترنت
- التزامن التلقائي عند استعادة الاتصال

## التحديثات والصيانة 🔧

للحصول على أحدث إصدار:
- تحديث ملف `service-worker.js`
- تحديث رقم الإصدار في `config.json`
- تفريغ ذاكرة التخزين المؤقت

## المساهمة 🤝

لاقتراح تحسينات أو الإبلاغ عن مشاكل، يرجى الاتصال عبر معلومات الأمان.
